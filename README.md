# CV Analyzer AI 🚀

## 📌 Description

Application full stack utilisant l'intelligence artificielle pour analyser des CV.

Fonctionnalités :

* Upload de CV (PDF)
* Analyse automatique
* Classification (Bon / Mauvais CV)
* Score de qualité

## 🧠 Technologies

* Python (Machine Learning - scikit-learn)
* Spring Boot (Backend)
* Angular (Frontend)

## 📊 Objectif

Automatiser la sélection de CV pour améliorer les processus de recrutement.

## ⚙️ Architecture

Frontend → Backend (Spring Boot) → API IA (Python)
